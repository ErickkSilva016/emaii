# Assets do login

Coloque nesta pasta os arquivos finais fornecidos para a identidade visual:

- `logo.png` - logo exibida no topo do painel de login.
- `login-background.jpeg` - imagem de fundo do painel direito do login.

O frontend usa a pasta `frontend/assets/` na fonte e publica seus arquivos em
`assets/`. Preserve esses nomes para manter os caminhos relativos no XAMPP e
no build estático do Netlify.
